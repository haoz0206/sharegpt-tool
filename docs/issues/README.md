# datasets Issue Tracker

This directory tracks local maintenance issues for the ShareGPT dataset utils
submodule. Issues are intentionally lightweight and scoped to this submodule.

## Status Values

- `open`: planned but not implemented.
- `in_progress`: currently being implemented.
- `done`: completed and covered by tests or documentation.
- `deferred`: valid work, intentionally not part of the current pass.
